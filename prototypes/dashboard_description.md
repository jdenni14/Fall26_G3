# Student Task Tracker — Dashboard Prototype

**Created by:** Jordan Dennis  
**Group:** 3  
**Sprint:** 2

## Purpose
The Dashboard helps college students organize assignments and keep track of deadlines.

## Features
- Displays upcoming assignments.
- Shows assignment due dates.
- Tracks assignment progress.
- Includes an Add New Task button.

## Target Users
College students who need to manage their coursework and assignments.

## Prototype Status
The initial Dashboard design is complete. Additional functionality will be developed in future sprints.
