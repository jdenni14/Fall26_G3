## Product Vision Statement

For college students who need a simple way to organize coursework, Student Task Tracker is a web application that keeps assignments, due dates, and completion status in one place. Unlike a basic paper to-do list, it allows students to update tasks, organize them by course, and view upcoming deadlines. The goal is to help students keep track of their responsibilities and plan their work.

## Proposed Features

- Add an assignment with its course, title, and due date.
- View assignments in a task list.
- Edit or delete an assignment.
- Mark assignments as complete.
- Filter assignments by course or completion status.
- Save tasks locally in the browser so they remain available after the page is closed.
